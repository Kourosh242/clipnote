# نصب / Installation

## فارسی

1. ZIP نسخهٔ `1.3.3` را از [Release](https://github.com/Kourosh242/clipnote/releases/tag/1.3.3) دانلود و استخراج کنید.
2. `chrome://extensions` یا `edge://extensions` را باز کنید.
3. Developer mode را فعال کنید، سپس **Load unpacked** را بزنید.
4. پوشهٔ `clipnote-v1.3.3` را انتخاب کنید. برای به‌روزرسانی، ZIP جدید را استخراج و در صفحهٔ افزونه Reload کنید.

## English

Download and extract the `1.3.3` release ZIP, open the browser extensions page, enable Developer mode, choose **Load unpacked**, and select `clipnote-v1.3.3`.
