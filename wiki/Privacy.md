# Privacy

[English](Home) · [فارسی](خانه)

ClipNote does not run a server and does not collect analytics.

**Stays on the device:** notes, settings, hashed locks, Quick Save source metadata.

**Leaves the device only for updates:** a public GitHub Releases/tags request that does not include note content.

Full statement: https://kourosh242.github.io/clipnote/privacy.html
