# راهنمای کاربر / User Guide

## فارسی

از Popup متن را وارد و ذخیره کنید؛ با انتخاب متن در هر صفحه، راست‌کلیک و **ذخیره در ClipNote** آن را سریع ثبت کنید. عنوان، برچسب، رنگ و Workspace را بعداً ویرایش کنید. جست‌وجو روی عنوان، محتوا، دسته‌بندی و برچسب انجام می‌شود. Markdown را در حالت Preview ببینید. Pin و Favorite برای دسترسی سریع‌اند.

برای یادداشت حساس، Protection را باز کنید و Password یا PIN و در صورت نیاز پرسش بازیابی تنظیم کنید. پس از قفل، محتوای یادداشت بدون بازکردن قفل نمایش داده نمی‌شود.

## English

Capture from the popup or select text on any page and use the ClipNote context-menu item. Search title, content, category, and tags; organize notes with workspaces, colors, pins, and favorites. Use Markdown preview for formatted notes. Protect sensitive notes with a password/PIN and optional recovery question.
