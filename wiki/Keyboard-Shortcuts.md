# Keyboard Shortcuts

[English](Home) · [فارسی](خانه)

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Open popup | Ctrl+Shift+N | ⌘+Shift+N |
| New note | Ctrl+N | ⌘+N |
| Save | Ctrl+S | ⌘+S |
| Search | Ctrl+F | ⌘+F |
| Undo in popup | Ctrl+U | ⌘+U |
| Undo in manager | Ctrl+Alt+U | Ctrl+Alt+U |
| Close / back | Esc | Esc |
