# Quick Start

[English](Home) · [فارسی](خانه)

1. Press `Ctrl+Shift+N` (`⌘+Shift+N` on macOS) to open the popup.
2. Click **New**, write a title and body, save.
3. On any website: select text → right-click → **Save to ClipNote**.
4. Open the manager for workspaces, Markdown split view, locks, and backups.
5. Settings → Language → فارسی if you want Vazirmatn and RTL.
