# حریم خصوصی و داده / Privacy and Data

## فارسی

ClipNote سرویس ابری ندارد و یادداشت‌ها را در `chrome.storage.local` نگه می‌دارد. برای بررسی نسخه فقط metadata انتشارهای GitHub خوانده می‌شود؛ متن یادداشت ارسال نمی‌شود. مجوزهای کلیپ‌بورد برای خواندن/نوشتن، context menu و notification برای امکانات اصلی‌اند. پیش از حذف افزونه Export JSON بگیرید.

## English

ClipNote has no cloud backend. Notes remain in `chrome.storage.local`; GitHub is queried only for release metadata and note content is never uploaded. Clipboard, context-menu, notification, storage, and alarm permissions support the documented features. Export JSON before uninstalling.
