# Features

[English](Home) · [فارسی](خانه)

- Toolbar popup and full manager share the same local database
- Workspaces, categories, tags, pin, favorite
- Timeline groups: Today, Yesterday, This week, This month, Older
- Smart tag suggestions for common programming keywords
- Markdown: headings, lists, tables, images, links, fenced code with Copy
- Quick Save from the context menu, including page title and URL
- Themes, dark mode, font size, animations, auto-save
- JSON backup with merge import, TXT export
- GitHub update checker (public version only)
