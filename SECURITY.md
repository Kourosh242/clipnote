# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.3.x | Yes |

## Reporting a vulnerability

Please open a private security advisory on GitHub if you can, or create an issue without exploit details.

ClipNote stores notes locally. Password and PIN locks use PBKDF2-SHA256 with a random salt. This is note-level protection inside the extension, not full profile encryption.

Do not send real user notes or live credentials in a public issue.
