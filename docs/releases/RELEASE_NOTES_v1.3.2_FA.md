## خلاصه نسخه ۱.۳.۲

این نسخه یک انتشار **پایدارسازی و امنیتی** است. تمرکز اصلی روی رفع باگ‌های هم‌زمانی، بهبود Markdown، پاک‌سازی مهاجرت داده‌ها، و شفاف‌سازی حریم خصوصی بوده است.

### چرا این نسخه مهم است؟

- اگر چند تب یا پنجره هم‌زمان یادداشت ذخیره می‌کردید، احتمال تداخل وجود داشت. حالا با **Web Locks** و ادغام آخرین داده‌ها، این مشکل برطرف شده.
- وارد کردن فایل پشتیبان (Import) و خواندن فایل‌ها حالا خطاها را واضح نشان می‌دهد و دیگر پیام موفقیت اشتباه نمی‌بینید.
- پشتیبان‌های خراب یا با نسخه ناسازگار، با اعتبارسنجی نسخه و حجم فایل، رد می‌شوند.
- Markdown قابل اعتمادتر شده: code block، لینک‌های امن، URLهای دارای پرانتز، لیست‌های تو در تو، و دکمه کپی کد در پاپ‌آپ درست کار می‌کند.

## رفع‌شده‌ها (Fixed)

- **هم‌زمانی:** مقاوم‌سازی ذخیره‌سازی هم‌زمان با Web Locks و merge آخرین state
- **خطاها:** مدیریت صریح خطاهای Storage، Import و FileReader
- **مهاجرت:** پاک‌سازی داده‌های null، خراب و شناسه‌های تکراری در migrateStorageData
- **Markdown:** اصلاح code block (عدم double-escape)، لینک‌های امن (جلوگیری از javascript:), URLهای دارای پرانتز، فهرست‌های تو‌در‌تو
- **پاپ‌آپ:** اصلاح از دست رفتن state، پیشنهادهای نادیده‌گرفته‌شده، دسته‌بندی Quick Capture و یادداشت‌های حذف‌شده در تب دیگر
- **به‌روزرسانی:** اصلاح بررسی نسخه، SemVer سخت‌گیرانه (فقط vX.Y.Z)، فیلتر prerelease، cache زمانی و اعلان‌های ناموفق
- **تنظیمات:** بازگردانی وضعیت Sidebar و پاک‌سازی کامل همه کلیدها در Clear All Data
- **مجوزها:** کاهش permissionهای غیرضروری و تعیین حداقل Chrome 111
- **رابط:** اصلاح دسترسی Responsive به Settings، Category و Tag بدون تغییر زبان بصری

## تغییرکرده (Changed)

- نسخه افزونه و پوشه سورس به `1.3.2` ارتقا یافت
- مستندات امنیت، محدودیت قفل محلی، Backup و Import/Export شفاف‌تر شدند
- ترجمه فارسی `discardChanges` اضافه شد (تغییرات ذخیره‌نشده؟)

## امنیت و حریم خصوصی

> **نکته مهم درباره قفل:** Password/PIN فقط دسترسی داخل رابط ClipNote را محدود می‌کند و **رمزنگاری محتوای ذخیره‌شده نیست**. خروجی JSON/TXT ممکن است متن یادداشت قفل‌شده را شامل شود؛ فایل پشتیبان را محرمانه نگه دارید.

- همه داده‌ها در `chrome.storage.local` دستگاه شما می‌ماند
- هیچ آنالیتیکس، تبلیغ یا سرور ClipNote برای محتوای خصوصی وجود ندارد
- تنها ارتباط شبکه‌ای، خواندن متادیتای عمومی ریلیز GitHub برای اعلان نسخه جدید است

## نصب سریع (فارسی)

### قبل از هر چیز: پشتیبان بگیرید!

1. در ClipNote به **تنظیمات / Settings** بروید
2. از بخش **Import / Export** گزینه **Export JSON** را بزنید
3. فایل JSON را در جای امن نگه دارید

### نصب v1.3.2

1. فایل [`clipnote-v1.3.2.zip`](https://github.com/Kourosh242/clipnote/releases/download/v1.3.2/clipnote-v1.3.2.zip) را از ریلیز دانلود و استخراج کنید
2. `chrome://extensions/` را باز کنید و **Developer mode** را فعال کنید
3. **Load unpacked** را بزنید
4. پوشه استخراج‌شده `clipnote` را انتخاب کنید؛ `manifest.json` باید مستقیماً داخل آن باشد
5. برای به‌روزرسانی، بعد از جایگزینی پوشه روی **Reload** کلیک کنید

> فایل ZIP فقط در Releases منتشر می‌شود و در شاخه main قرار ندارد.
