راهنمای نصب و شروع سریع

کل فرایند نصب کمتر از دو دقیقه طول می‌کشد. هیچ حساب کاربری، ثبت‌نام یا سروری در کار نیست.

پیش‌نیازها

  • گوگل کروم، یا هر مرورگر مبتنی بر کرومیوم که از Manifest V3 پشتیبانی می‌کند (مثل اج، بریو یا اپرا).
  • فایل زیپ نسخه ۱.۳.۱ از بخش Releases مخزن کلیپ‌نوت در گیتهاب (فایل clipnote_1.3.1.zip).
  • یک پوشه پایدار روی کامپیوتر که زیپ را آنجا استخراج کنید؛ تا وقتی اکستنشن نصب است، آن پوشه را حذف یا جابه‌جا نکنید.

نصب مرحله‌به‌مرحله

  1. فایل clipnote_1.3.1.zip را دانلود و در یک پوشه ثابت Extract کنید. بعد از استخراج باید فایلی به نام manifest.json داخل پوشه ببینید.
  2. در نوار آدرس کروم بنویسید chrome://extensions و اینتر بزنید.
  3. گزینه Developer mode را در گوشه بالای صفحه روشن کنید.
  4. روی Load unpacked کلیک کنید و همان پوشه‌ای را انتخاب کنید که manifest.json داخل آن است.
  5. آیکون کلیپ‌نوت به لیست اکستنشن‌ها اضافه می‌شود. با کلیک روی آیکون پازل در نوار ابزار، آن را Pin کنید تا همیشه در دسترس باشد.
  6. با Ctrl + Shift + N پاپ‌آپ را باز کنید؛ اولین نصب به‌صورت خودکار صفحه تنظیمات را هم باز می‌کند.
چرا Load unpacked؟

این نسخه به‌صورت پوشه باز نصب می‌شود، نه از فروشگاه. یعنی همه کد روی دستگاه شماست و می‌توانید خودتان بازش کنید و بخوانید.

اولین یادداشت شما

  1. پاپ‌آپ را باز کنید و روی دکمه جدید بزنید (یا Ctrl + N).
  2. عنوان و متن را بنویسید. می‌توانید فضای کاری، دسته‌بندی، برچسب‌ها و رنگ یادداشت را هم انتخاب کنید.
  3. با Ctrl + S ذخیره کنید. اگر ذخیره خودکار فعال باشد، نیازی به این کار نیست.

ذخیره سریع از هر صفحه وب

  1. روی هر صفحه‌ای بخشی از متن را با ماوس انتخاب کنید.
  2. راست‌کلیک کنید و Save to ClipNote را انتخاب کنید.
  3. یادداشت با عنوان صفحه، آدرس صفحه، زمان ثبت و برچسب‌های پیشنهادی در فضای کاری فعلی ذخیره می‌شود و یک اعلان تأیید می‌بینید.

فارسی کردن رابط

  1. پاپ‌آپ را باز کنید و روی آیکون باز کردن مدیریت کلیک کنید تا صفحه مدیر کامل باز شود.
  2. به بخش تنظیمات بروید.
  3. در کارت زبان، مقدار را روی فارسی بگذارید و ذخیره کنید.
  4. از این لحظه همه متن‌ها فارسی، فونت وزیرمتن و چیدمان راست‌چین می‌شود.

اگر نصب نشد

  • پوشه اشتباه را انتخاب کرده‌اید: باید پوشه‌ای باشد که مستقیماً manifest.json داخلش است، نه پوشه بالایی زیپ.
  • Developer mode خاموش است.
  • پوشه را بعد از نصب جابه‌جا یا حذف کرده‌اید؛ اکستنشن را Remove و دوباره از مسیر جدید Load unpacked کنید.
  • اگر میان‌بر Ctrl + Shift + N کار نمی‌کند، در صفحه chrome://extensions/shortcuts می‌توانید آن را تغییر دهید.

Install & quick start

The whole installation takes under two minutes. No account, no sign-up, no server.

Requirements

  • Google Chrome, or any Chromium-based browser that supports Manifest V3 (such as Edge, Brave or Opera).
  • The 1.3.1 zip file from the Releases section of the ClipNote repository on GitHub (clipnote_1.3.1.zip).
  • A stable folder on your computer to extract the zip into; do not delete or move it while the extension stays installed.

Step-by-step installation

  1. Download clipnote_1.3.1.zip and extract it into a fixed folder. After extracting you should see a file called manifest.json.
  2. Type chrome://extensions in the address bar and press Enter.
  3. Turn on Developer mode at the top of the page.
  4. Click Load unpacked and select the folder that contains manifest.json.
  5. ClipNote appears in the extension list. Click the puzzle icon in the toolbar and Pin it so it is always reachable.
  6. Press Ctrl + Shift + N to open the popup; a fresh install also opens the settings page automatically.
Why Load unpacked?

This build is installed from a folder, not from a store. That means the whole source stays on your device and you can open and read it yourself.

Your first note

  1. Open the popup and press the New button (or Ctrl + N).
  2. Type a title and content. You can also pick the workspace, category, tags and note colour.
  3. Press Ctrl + S to save — not needed when auto save is on.

Quick Save from any web page

  1. Select a piece of text with the mouse on any page.
  2. Right-click and choose Save to ClipNote.
  3. The note is stored in the current workspace with the page title, page URL, capture time and suggested tags, and a confirmation notification appears.

Switching the interface language

  1. Open the popup and click the Open Manager icon to open the full manager tab.
  2. Go to Settings.
  3. In the Language card choose فارسی and save.
  4. From now on all labels are Persian, rendered with Vazirmatn in a right-to-left layout.

If the install fails

  • You selected the wrong folder: pick the folder that directly contains manifest.json, not the outer zip folder.
  • Developer mode is still off.
  • The folder was moved or deleted after installing; remove the extension and load it again from the new path.
  • If Ctrl + Shift + N does nothing, change it on chrome://extensions/shortcuts.
