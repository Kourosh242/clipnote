Privacy

ClipNote is a local-first Chrome extension. We do not operate a ClipNote server and we do not collect accounts, analytics, or advertising identifiers.

What stays on your device

  • Notes, titles, tags, categories, workspaces, colors, pin/favorite flags
  • Settings including language, theme, and font size
  • Hashed note passwords / PINs and optional recovery answers
  • Source page title and URL when you use Quick Save

What leaves your device

Only if you (or the background alarm) check for updates: a public request to GitHub’s release/tag API. The request does not include note content.

Permissions

storage, clipboardRead, clipboardWrite, activeTab, contextMenus, notifications, and alarms are used for local features. Host access is limited to GitHub for version checks.
