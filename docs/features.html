دو سطح کار: پاپ‌آپ و مدیر

⚡

پاپ‌آپ نوار ابزار

  • یادداشت سریع بدون باز شدن تب جدید
  • نمای کلی یا تایم‌لاین، با فیلتر همه / پین‌شده / علاقه‌مندی
  • باز کردن، ویرایش، کپی، پین، علاقه‌مندی و حذف یادداشت
  • نمایش بنر «ذخیره سریع» برای آخرین چیزی که با راست‌کلیک ذخیره کرده‌اید
🗂

مدیر کامل (تب جداگانه)

  • نوار کناری با فضای کاری، دسته‌بندی و برچسب‌ها
  • ویرایشگر بزرگ‌تر با نمای دو ستونه، فقط ادیتور یا فقط پیش‌نمایش
  • مدیریت فضای کاری و دسته‌بندی (افزودن، تغییر نام، حذف)
  • تنظیمات، بکاپ، ورود و خروجی داده

هر دو سطح روی یک پایگاه داده محلی مشترک کار می‌کنند. تغییری که در پاپ‌آپ می‌دهید فوراً در مدیر دیده می‌شود و برعکس.

فضای کاری و دسته‌بندی

فضای کاری سطح بالای جداسازی است؛ مثلاً «کار»، «شخصی»، «تحصیل». در اولین نصب یک فضای کاری پیش‌فرض به نام General ساخته می‌شود و همیشه حداقل یک فضای کاری وجود دارد. اگر فضایی را حذف کنید، یادداشت‌هایش به فضای پیش‌فرض منتقل می‌شوند.

دسته‌بندی لایه دوم است و اختیاری. دسته‌های پیش‌فرض عبارت‌اند از: Work، Personal، Programming، Shopping، Ideas و Passwords. می‌توانید دسته دلخواه اضافه یا ویرایش کنید؛ با حذف یک دسته، یادداشت‌هایش بدون دسته می‌مانند.

برچسب‌های سریع، سفارشی و هوشمند

برچسب‌ها را می‌توانید دستی بنویسید (با کاما جدا کنید) یا از چیپ‌های آماده انتخاب کنید. برچسب‌هایی که بیشتر استفاده می‌شوند بالاتر از بقیه پیشنهاد می‌شوند. برچسب‌های پیش‌فرض: python، css، api_key، text، md.

علاوه بر آن، کلیپ‌نوت محتوای یادداشت را با یک موتور قواعد تحلیل می‌کند و برچسب پیشنهادی می‌دهد. با دکمه افزودن همه همه پیشنهادها یک‌جا اضافه می‌شوند و هر پیشنهاد را هم می‌توانید رد کنید تا دوباره تکرار نشود.

پین، علاقه‌مندی، رنگ و تایم‌لاین

  • پین: یادداشت‌های پین‌شده همیشه بالای لیست می‌مانند.
  • علاقه‌مندی: یک فیلتر جدا برای یادداشت‌های مهم، هم در پاپ‌آپ و هم در مدیر.
  • رنگ: شش رنگ قرمز، آبی، سبز، نارنجی، بنفش و خاکستری. رنگ پیش‌فرض یادداشت‌های جدید در تنظیمات قابل تغییر است.
  • مرتب‌سازی: اول پین‌شده‌ها، بعد بقیه بر اساس آخرین زمان ویرایش (تازه‌ترین بالا).
  • تایم‌لاین: در این نما یادداشت‌ها در گروه‌های امروز، دیروز، این هفته، این ماه و قدیمی‌تر دسته‌بندی می‌شوند.

جستجو

با Ctrl + F به کادر جستجو بروید. جستجو هم‌زمان در عنوان، متن، برچسب‌ها و دسته‌بندی انجام می‌شود و به بزرگی و کوچکی حروف حساس نیست. در مدیر می‌توانید جستجو را با فضای کاری، دسته یا برچسب انتخاب‌شده ترکیب کنید.

بررسی نسخه جدید

کلیپ‌نوت خودش را به‌روز نمی‌کند، اما به شما خبر می‌دهد نسخه جدیدتری آمده است:

  • اولین بررسی حدود ۵ دقیقه بعد از نصب یا باز شدن مرورگر، و بعد از آن هر ۶ ساعت یک بار.
  • نتیجه تا ۶ ساعت کش می‌شود تا درخواست تکراری زده نشود.
  • تنها چیزی که خوانده می‌شود شماره نسخه است؛ یادداشت‌ها هرگز فرستاده نمی‌شوند.
  • برای هر نسخه فقط یک بار اعلان می‌بینید و با کلیک روی آن صفحه ریلیز باز می‌شود.
  • وضعیت نسخه در بخش تنظیمات هم نمایش داده می‌شود («به‌روز هستید» یا وجود نسخه جدیدتر).

Two surfaces: popup and manager

⚡

Toolbar popup

  • Quick capture without opening a new tab
  • Overview or timeline view, with all / pinned / favourites filters
  • Open, edit, copy, pin, favourite and delete notes
  • A Quick Save banner for the last thing you saved with the right click
🗂

Full manager (own tab)

  • Sidebar with workspaces, categories and tags
  • A larger editor with split view, editor only or preview only
  • Workspace and category management (add, rename, delete)
  • Settings, backup, import and export

Both surfaces share one local database. A change made in the popup appears in the manager instantly, and the other way round.

Workspaces and categories

Workspaces are the top level of separation, for example Work, Personal or Study. A default workspace called General is created on install and there is always at least one workspace. Deleting a workspace moves its notes to the default one.

Categories are the optional second layer. The defaults are Work, Personal, Programming, Shopping, Ideas and Passwords. You can add or edit your own; deleting a category leaves its notes uncategorised.

Quick, custom and smart tags

Type tags manually (comma separated) or pick them from ready-made chips. Tags you use more often are suggested first. The default tags are python, css, api_key, text and md.

On top of that, ClipNote runs the note content through a rule engine and suggests tags. Accept All adds every suggestion at once, and any suggestion can be dismissed so it is not repeated.

Pin, favourite, colour and timeline

  • Pin: pinned notes always stay at the top of the list.
  • Favourite: a separate filter for important notes, in both popup and manager.
  • Colour: six colours — red, blue, green, orange, purple and grey. The default colour for new notes is configurable.
  • Sorting: pinned notes first, then everything else by last update time (newest first).
  • Timeline: in this view notes are grouped into Today, Yesterday, This Week, This Month and Older.

Markdown editor

The editor has three modes: split view, editor only and preview only. The preview updates as you type and every code block has a copy button.

Content safety

Note text is always escaped before it becomes HTML, so writing a script tag inside a note never executes anything.

Search

Press Ctrl + F to jump to the search box. Search runs across title, content, tags and category at once and is case insensitive. In the manager you can combine it with the selected workspace, category or tag.

Choosing Persian turns the whole interface right-to-left and switches to the local Vazirmatn font. The font is bundled with the extension, so it renders correctly without an internet connection.

Update check

ClipNote never updates itself, but it tells you when a newer version exists:

  • The first check runs about 5 minutes after install or browser start, then every 6 hours.
  • The result is cached for 6 hours so no duplicate requests are made.
  • Only the version number is read; notes are never sent anywhere.
  • You get one notification per version, and clicking it opens the release page.
  • The version status is also shown in Settings (“you are up to date” or a newer version found).
