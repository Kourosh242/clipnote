ClipNote wiki

ClipNote is a Manifest V3 Chrome extension that turns your clipboard and selected web text into a private local notebook. Version 1.3.0 is maintained by Kourosh & Mehdi.

This wiki is the English handbook. The Persian handbook is a separate page: ویکی فارسی.

All notes stay in chrome.storage.local. ClipNote does not create accounts and does not run a backend.

Installation

  1. Download clipnote_1.3.0.zip.
  2. Extract the archive. You should see a folder that contains manifest.json, popup.html, options.html, and background.js.
  3. Open Chrome and visit chrome://extensions.
  4. Enable Developer mode.
  5. Click Load unpacked and choose that folder.
  6. Pin ClipNote to the toolbar.

After the first install, ClipNote opens the Settings page so you can pick a language and theme.

Quick start

  1. Press Ctrl+Shift+N (or ⌘+Shift+N on a Mac) to open the popup.
  2. Click New, write a title and body, then save.
  3. On any website, select text → right-click → Save to ClipNote.
  4. Open the manager from the popup for the full editor, workspaces, and settings.

Popup

The toolbar popup is the daily inbox:

  • Search across title, content, tags, and categories.
  • Filter by workspace, All / Pinned / Favorites.
  • Switch Overview and Timeline (Today, Yesterday, This week…).
  • Create a quick note with color, pin, favorite, and smart tags.
  • Open, edit, copy, or delete a note without leaving the popup.
  • Unlock protected notes, including recovery-question flow.

Manager

The manager (options.html) is the full notebook:

  • Sidebar with All Notes, workspaces, categories, and used tags.
  • Create, rename, or delete workspaces and categories.
  • Sort by last updated, created date, or title.
  • Split / editor / preview Markdown workspace.
  • Auto-save, undo, paste from the system clipboard.
  • Lock, change lock, remove lock, and set a recovery question.

Notes & Markdown

A note stores title, body, tags, category, color, workspace, pin/favorite flags, source metadata, and an optional lock.

Markdown support includes:

  • Headings # to ######
  • Bold, italic, strike, inline code
  • Fenced code blocks with a Copy button
  • Lists, blockquotes, tables, images, and links

If you save from the context menu, ClipNote also keeps the page title, URL, and capture time.

Workspaces, categories, tags

  • Workspaces isolate projects. Deleting a workspace moves its notes to another workspace.
  • Categories are labels such as Work, Personal, Programming, Shopping, Ideas, Passwords.
  • Tags can be typed, picked from Quick Tags, or accepted from Smart Suggestions.

Smart rules look for Python, JavaScript, React, Vue, CSS, HTML, API, Node.js, SQL, Docker, Linux, Git, JSON, Markdown, regex, and bug-related wording.

Security

  • Password or exactly 4-digit PIN per note.
  • Secrets are derived with PBKDF2-SHA256, 150,000 iterations, random salt.
  • The original password is never stored.
  • An optional recovery question stores only a hash of the answer.
  • Locked previews stay hidden until the current browser session unlocks them.

This is local protection, not a full disk-encryption product. Anyone with OS access to the Chrome profile can still read storage. Use it for convenient note privacy, not as a password vault replacement.

Import & export

  • Export JSON — full backup of notes, settings, workspaces, categories, and custom tags.
  • Export TXT — readable dump of every note.
  • Import JSON — merges by id, keeps the newest updatedAt, and unions workspaces/tags.
  • Clear all data — resets the extension after a confirmation prompt.

Settings & appearance

  • Dark mode
  • Themes: Blue, Green, Purple, Orange, Dark Pro
  • Font size 12–20px
  • Animations on/off
  • Auto-save
  • Default note color
  • Interface language: English or فارسی (Vazirmatn + RTL)

Updates

ClipNote checks GitHub Releases every six hours and when you click Check for Updates. If a newer version exists, a badge and banner appear. Clicking the notification opens the release page. Only the public version number is requested — notes are never uploaded.

Privacy

See the full statement on the privacy page. Short version: local storage only, optional GitHub version check, no analytics, no ads.

FAQ

Chrome only? It is built and tested as a Chrome Manifest V3 extension. Other Chromium browsers may load it, but they are unofficial.

Lost a PIN? Use the recovery question if you set one. Otherwise that note cannot be previewed.

Where is the data file? Inside the Chrome user profile storage for this extension. Export JSON if you want a portable copy.
