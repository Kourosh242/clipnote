سوالات متداول

پاسخ پرسش‌هایی که بیشتر پرسیده می‌شوند، همراه با راه‌حل‌های رفع اشکال.

آیا کلیپ‌نوت برای کار کردن به اینترنت نیاز دارد؟

خیر. همه یادداشت‌ها محلی ذخیره می‌شوند و کل رابط، از جمله فونت فارسی، داخل بسته اکستنشن است. تنها ارتباط شبکه‌ای، خواندن شماره نسخه از گیتهاب برای اطلاع دادن نسخه جدید است؛ اگر آفلاین باشید فقط همین اطلاع‌رسانی کار نمی‌کند و بقیه امکانات بدون مشکل اجرا می‌شوند.

رمز یا پین یک یادداشت را فراموش کرده‌ام، چه کار کنم؟

اگر موقع قفل کردن سوال بازیابی گذاشته باشید، در پنجره باز کردن یادداشت گزینه بازیابی رمز را بزنید و پاسخ را وارد کنید. اگر سوال بازیابی نداشته باشید، امکان بازگرداندن رمز وجود ندارد؛ در این حالت از بخش حفاظت در ویرایشگر می‌توانید قفل را حذف کنید. توجه کنید که قفل فقط نمایش متن را می‌بندد و محتوا رمزنگاری نمی‌شود؛ جزئیات در صفحه امنیت آمده است.

چطور یادداشت‌ها را به کامپیوتر دیگر منتقل کنم؟

از تنظیمات ← Export JSON بکاپ بگیرید، اکستنشن را روی دستگاه جدید نصب کنید و همان فایل را با Import JSON وارد کنید. ورود اطلاعات با داده موجود ادغام می‌شود و چیزی را پاک نمی‌کند.

چرا اکستنشن خودش به‌روز نمی‌شود؟

چون به‌صورت پوشه باز (Load unpacked) نصب می‌شود، نه از فروشگاه؛ پس کروم نمی‌تواند خودش جایگزینش کند. کلیپ‌نوت هر ۶ ساعت شماره نسخه را چک می‌کند و اگر نسخه جدیدتری باشد اعلان می‌دهد. برای به‌روزرسانی، نسخه جدید را دانلود و استخراج کنید و در chrome://extensions دکمه Reload را بزنید یا پوشه جدید را Load unpacked کنید.

قبل از به‌روزرسانی باید چه کار کنم؟

یک خروجی JSON بگیرید. مرحله مهاجرت خودکار داده‌ها را با نسخه جدید هم‌خوان می‌کند، اما داشتن یک فایل بکاپ همیشه مطمئن‌تر است.

اگر اکستنشن را حذف (Remove) کنم داده‌هایم چه می‌شود؟

با حذف اکستنشن، داده‌های ذخیره‌شده در حافظه محلی کروم هم پاک می‌شود. پس قبل از حذف، حتماً Export JSON بگیرید.

آیا روی اج، بریو یا اپرا هم کار می‌کند؟

کلیپ‌نوت برای کروم و Manifest V3 ساخته شده است. مرورگرهای مبتنی بر کرومیوم معمولاً با همان روش Load unpacked آن را می‌پذیرند، اما این حالت‌ها به‌صورت رسمی آزمایش نشده‌اند.

میان‌بر Ctrl + Shift + N کار نمی‌کند.

این کلید ممکن است توسط مرورگر یا یک اکستنشن دیگر اشغال شده باشد. به chrome://extensions/shortcuts بروید و میان‌بر «Open ClipNote popup» را روی ترکیب دیگری تنظیم کنید. همیشه می‌توانید با کلیک روی آیکون کلیپ‌نوت هم پاپ‌آپ را باز کنید.

گزینه Save to ClipNote را در راست‌کلیک نمی‌بینم.

این گزینه فقط وقتی متن را انتخاب کرده باشید ظاهر می‌شود. اگر هنوز دیده نمی‌شود، یک بار مرورگر را کامل ببندید و دوباره باز کنید؛ منوی راست‌کلیک هنگام نصب و هنگام شروع به کار مرورگر ساخته می‌شود.

چطور رابط را فارسی و راست‌چین کنم؟

مدیر را باز کنید، به تنظیمات بروید و در کارت زبان مقدار را روی فارسی بگذارید و ذخیره کنید. فونت وزیرمتن و چیدمان راست‌چین خودکار فعال می‌شود.

آیا می‌توانم داخل یادداشت تصویر بگذارم؟

بله، با سینتکس مارک‌داون: ![توضیح](آدرس تصویر). تصویر از آدرسی که داده‌اید بارگذاری می‌شود، پس برای دیدنش به اینترنت نیاز دارید. خودِ فایل تصویر در اکستنشن ذخیره نمی‌شود.

اندازه متن برایم کوچک است.

در تنظیمات ← ظاهر لغزنده اندازه فونت را بین ۱۲ تا ۲۰ پیکسل تنظیم کنید. تم و حالت تاریک هم در همان بخش هستند.

اعلان نسخه جدید را دریافت نمی‌کنم.

برای هر نسخه فقط یک بار اعلان داده می‌شود و نتیجه بررسی تا ۶ ساعت کش می‌شود. همچنین اگر آفلاین باشید یا گیتهاب در دسترس نباشد، بررسی انجام نمی‌شود. وضعیت نسخه را همیشه می‌توانید در بالای صفحه تنظیمات ببینید.

چطور همه‌چیز را از صفر شروع کنم؟

در تنظیمات ← داده دکمه Clear All Data را بزنید. همه یادداشت‌ها، دسته‌ها، فضای کاری، برچسب‌ها و تنظیمات حذف می‌شوند و این کار برگشت‌پذیر نیست.

چطور نسخه نصب‌شده را بفهمم؟

در صفحه تنظیمات، بخش «وضعیت نسخه» شماره نسخه و وضعیت به‌روز بودن را نشان می‌دهد. همین شماره در کارت «درباره» هم تکرار شده است.

Frequently asked questions

Answers to the questions that come up most often, plus troubleshooting.

Does ClipNote need an internet connection?

No. All notes are stored locally and the whole interface, including the Persian font, is bundled inside the extension. The only network activity is reading the version number from GitHub to announce a new release; when you are offline only that notice is skipped and everything else works normally.

I forgot the password or PIN of a note, what now?

If you set a recovery question when locking, use Recover password in the unlock dialog and type the answer. Without a recovery question the secret cannot be restored; you can then remove the lock from the Protection panel in the editor. Remember that the lock only hides the text in the UI and does not encrypt it — details on the security page.

How do I move my notes to another computer?

Take a backup with Settings → Export JSON, install the extension on the new machine and load that file with Import JSON. Import merges with existing data and never deletes anything.

Why does the extension not update itself?

Because it is installed unpacked (Load unpacked) rather than from a store, Chrome cannot replace it automatically. ClipNote checks the version number every 6 hours and notifies you when something newer exists. To update, download and extract the new version and press Reload in chrome://extensions, or load the new folder.

What should I do before updating?

Export a JSON backup. The automatic migration step aligns your data with the new version, but having a backup file is always safer.

What happens to my data if I remove the extension?

Removing the extension also clears the data stored in Chrome's local storage. Always run Export JSON first.

Does it work in Edge, Brave or Opera?

ClipNote is built for Chrome and Manifest V3. Chromium-based browsers usually accept it with the same Load unpacked method, but those cases are not officially tested.

Ctrl + Shift + N does nothing.

The combination may already be taken by the browser or another extension. Open chrome://extensions/shortcuts and assign a different key to “Open ClipNote popup”. Clicking the ClipNote icon always opens the popup as well.

I do not see Save to ClipNote in the right-click menu.

The item only appears when text is selected. If it is still missing, close and reopen the browser once; the context menu is created on install and on browser startup.

How do I make the interface Persian and right-to-left?

Open the manager, go to Settings, set the Language card to فارسی and save. Vazirmatn and the RTL layout are enabled automatically.

Can I put an image inside a note?

Yes, with Markdown syntax: ![alt](image url). The image loads from the address you give, so viewing it requires internet; the image file itself is not stored in the extension.

The text is too small for me.

Adjust the font size slider between 12 and 20 pixels under Settings → Appearance. The theme and dark mode live in the same section.

I never get the new-version notification.

Each version triggers only one notification and the check result is cached for 6 hours. If you are offline or GitHub is unreachable the check does not run. The version status is always visible at the top of Settings.

How do I start over from scratch?

Press Clear All Data under Settings → Data. All notes, categories, workspaces, tags and settings are removed and this cannot be undone.

How do I check which version I have?

The Settings page shows a Version Status section with the version number and whether you are up to date. The same number appears in the About card.
