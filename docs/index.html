شروع سریع

  1. فایل ZIP نسخهٔ 1.3.3 را از صفحهٔ Release بگیرید.
  2. در Chrome/Edge، chrome://extensions را باز و Developer mode را فعال کنید.
  3. روی Load unpacked بزنید و پوشهٔ استخراج‌شدهٔ clipnote-v1.3.3 را انتخاب کنید.

قابلیت‌ها

  • ذخیره از Popup، کلیپ‌بورد و منوی راست‌کلیک؛ همراه با عنوان صفحه و URL منبع.
  • جست‌وجو، فیلتر، مرتب‌سازی، Timeline، Workspace، دسته‌بندی و برچسب.
  • Markdown، پیش‌نمایش، کپی کد، رنگ، Pin و Favorite.
  • قفل یادداشت با رمز/PIN و Recovery Question.
  • پشتیبان JSON، خروجی TXT، تم‌ها و رابط کامل فارسی RTL.
  • بررسی دوره‌ای تگ‌های Release در GitHub و اعلان نسخهٔ جدید (سازگار با زبان رابط).

پشتیبان و حریم خصوصی

یادداشت‌ها در chrome.storage.local ذخیره می‌شوند و سرویس ابری ندارند. از Settings خروجی JSON بگیرید و فایل را امن نگه دارید. مجوز GitHub فقط برای خواندن Releaseها و بررسی به‌روزرسانی است.

عیب‌یابی

  • اگر منوی راست‌کلیک نیست، افزونه را Reload کنید و یک صفحهٔ عادی را باز کنید.
  • اگر داده‌ای دیده نمی‌شود، Workspace انتخاب‌شده را بررسی یا Import JSON کنید.
  • اگر یادداشت قفل‌شده باز نمی‌شود، مطمئن شوید از نسخهٔ 1.3.3 استفاده می‌کنید (این نسخه باگ از دست رفتن کلید رمزنگاری را برطرف کرده است).
  • برای گزارش، نسخهٔ مرورگر و مراحل بازتولید را در Issues بفرستید.

English guide

Install: download the 1.3.3 ZIP, open chrome://extensions, enable Developer mode, select Load unpacked, and choose clipnote-v1.3.3.

What it includes

Quick capture, context-menu saving, full-text search, workspaces, categories, smart tags, Markdown preview, encrypted note locks with recovery, JSON/TXT backup, themes, RTL Persian UI, and GitHub release notifications.

Privacy

Notes stay in chrome.storage.local. No note content is uploaded. GitHub access is limited to reading release metadata for update checks.

Developing

The extension is plain Manifest V3 with no build step. Load clipnote-v1.3.3 as an unpacked extension and test popup, options, context menu, import/export, lock, and update flows.
