امنیت داده‌ها

قبل از تغییر، پشتیبان بگیر

یادداشت‌ها فقط روی دستگاه تو هستند. یک خروجی JSON، راه مطمئن نگه‌داشتن آن‌ها پیش از نصب مجدد یا به‌روزرسانی است.

01

تنظیمات را باز کن

در ClipNote وارد Settings / تنظیمات شو و بخش Import / Export را پیدا کن.

02

Export JSON را انتخاب کن

فایل پشتیبان را در جایی امن خارج از پوشهٔ افزونه ذخیره کن.

03

در صورت نیاز برگردان

پس از نصب، Import JSON را بزن. ورود JSON داده‌ها را با یادداشت‌های فعلی ادغام می‌کند.
