کلیپ‌نوت — دفترچه یادداشت کلیپ‌بورد کروم

یک دفترچه یادداشت سریع، امن و کاملاً محلی برای گوگل کروم. متن‌ها را از هر صفحه‌ای با راست‌کلیک ذخیره کنید، دسته‌بندی کنید، برچسب بزنید و روی هر یادداشت قفل بگذارید. هیچ داده‌ای به سروری فرستاده نمی‌شود.

نسخه ۱.۳.۱ Manifest V3 کاملاً آفلاین دوزبانه: فارسی / انگلیسی راست‌چین با فونت وزیرمتن

این ویکی چیست؟

این سایت، ویکی رسمی ClipNote روی GitHub Pages است. هرچه درباره نصب، امکانات، امنیت و بکاپ گرفتن لازم دارید، در پنج صفحه زیر جمع شده است. زبان پیش‌فرض سایت فارسی است؛ با دکمه EN بالای صفحه به انگلیسی بروید.

نصب مرحله‌به‌مرحله در کروم، پین کردن آیکون، ساخت اولین یادداشت و جدول کامل کلیدهای میان‌بر.

امکانات

فضای کاری، دسته‌بندی، برچسب هوشمند، مارک‌داون، تایم‌لاین، پین و علاقه‌مندی، تم‌ها و حالت‌های نمایش.

امنیت

قفل رمز یا پین ۴ رقمی با PBKDF2-SHA256، سوال بازیابی، دسترسی‌های واقعاً استفاده‌شده و حریم خصوصی.

🗄

داده و بکاپ

ساختار داده‌های ذخیره‌شده، خروجی JSON و TXT، قواعد ادغام در ورود اطلاعات و پاک کردن کامل داده‌ها.

سه کاری که بیشتر از همه استفاده می‌شود

  1. ذخیره سریع از هر صفحه: متن را انتخاب کنید، راست‌کلیک کنید و Save to ClipNote را بزنید. عنوان صفحه، آدرس و برچسب‌های پیشنهادی خودکار ثبت می‌شوند.
  2. یادداشت سریع با میان‌بر: با Ctrl + Shift + N پاپ‌آپ باز می‌شود، سپس Ctrl + N فرم یادداشت سریع را می‌آورد.
  3. قفل روی یادداشت‌های حساس: در ویرایشگر، بخش قفل را باز کنید، رمز یا پین ۴ رقمی بگذارید و در صورت نیاز سوال بازیابی اضافه کنید.

ClipNote — the clipboard notebook for Chrome

A fast, secure and fully local notebook for Google Chrome. Save selected text from any page with a right click, organise it into workspaces and categories, tag it automatically and lock individual notes. Nothing is ever sent to a server.

The three things you will use the most

  1. Quick Save from any page: select text, right-click and choose Save to ClipNote. Page title, URL and suggested tags are captured automatically.
  2. Quick note with a shortcut: Ctrl + Shift + N opens the popup, then Ctrl + N opens the quick capture form.
  3. Lock sensitive notes: in the editor open the lock panel, set a password or 4-digit PIN, and optionally add a recovery question.
Tip
