حریم خصوصی

کلیپ‌نوت یک افزونه محلی برای کروم است. ما سرور کلیپ‌نوت نداریم و حساب کاربری، آمارگیری یا شناسه تبلیغاتی جمع نمی‌کنیم.

چه چیزی روی دستگاه شما می‌ماند

  • یادداشت‌ها، عنوان‌ها، برچسب‌ها، دسته‌ها، فضاهای کاری، رنگ‌ها، پین و علاقه‌مندی
  • تنظیمات شامل زبان، تم و اندازه فونت
  • هش رمز / پین یادداشت و جواب اختیاری سوال بازیابی
  • عنوان و آدرس صفحه منبع وقتی از ذخیره سریع استفاده می‌کنید

چه چیزی از دستگاه خارج می‌شود

فقط اگر خودتان (یا هشدار پس‌زمینه) نسخه جدید را بررسی کنید: یک درخواست عمومی به API ریلیز/تگ گیت‌هاب. این درخواست محتوای یادداشت را ندارد.

مجوزها

مجوزهای storage، clipboardRead، clipboardWrite، activeTab، contextMenus، notifications و alarms برای امکانات محلی هستند. دسترسی میزبان فقط برای بررسی نسخه به گیت‌هاب محدود شده است.
