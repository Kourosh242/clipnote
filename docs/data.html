داده، بکاپ و جابه‌جایی

داده‌های شما کجا ذخیره می‌شود، فایل بکاپ چه شکلی است، هنگام ورود اطلاعات چه چیزی با چه چیزی ادغام می‌شود و چطور بدون از دست دادن یادداشت به کامپیوتر دیگر بروید.

داده‌ها کجا ذخیره می‌شوند

همه‌چیز در chrome.storage.local و با این کلیدها نگهداری می‌شود:

کلیدمحتوا
clipnote_notesهمه یادداشت‌ها
clipnote_settingsتنظیمات ظاهر، ویرایشگر و زبان
clipnote_workspacesفضاهای کاری
clipnote_categoriesدسته‌بندی‌ها
clipnote_custom_tagsبرچسب‌های سفارشی
clipnote_last_quick_saveاطلاعات آخرین ذخیره سریع برای بنر پاپ‌آپ
clipnote_update_infoنتیجه آخرین بررسی نسخه (کش ۶ ساعته)
clipnote_last_notified_versionنسخه‌ای که قبلاً برایش اعلان داده شده

ساختار یک یادداشت

هر یادداشت این فیلدها را دارد: id، title، content، tags، category، color، isFavorite، isPinned، createdAt، updatedAt، workspaceId، بخش source (نوع ثبت، عنوان صفحه، آدرس صفحه و زمان ثبت) و بخش lock برای قفل.

گرفتن خروجی (بکاپ)

در بخش تنظیمات ← داده سه دکمه وجود دارد:

  • Export JSON: فایل کامل بکاپ با نامی مثل clipnote-backup-2026-08-25.json. این فایل شامل یادداشت‌ها، تنظیمات، دسته‌بندی‌ها، فضای کاری، برچسب‌های سفارشی و اطلاعات آماری است و فرمت آن نسخه ۳ است.
  • Export TXT: یک فایل متنی خوانا برای آرشیو یا خواندن با ویرایشگر متن؛ برای هر یادداشت عنوان، فضای کاری، دسته، برچسب‌ها، تاریخ ساخت و ویرایش، آدرس منبع و متن کامل نوشته می‌شود.
  • Import JSON: وارد کردن یک فایل بکاپ با ادغام هوشمند (توضیح در پایین).

هنگام ورود اطلاعات چه اتفاقی می‌افتد

ورود اطلاعات، داده فعلی شما را پاک نمی‌کند؛ بلکه ادغام می‌کند:

  • فضاهای کاری: بر اساس شناسه ادغام می‌شوند؛ نام از فایل ورودی گرفته می‌شود و قدیمی‌ترین تاریخ ساخت نگه داشته می‌شود. فضای پیش‌فرض همیشه تضمین می‌شود.
  • یادداشت‌ها: بر اساس شناسه ادغام می‌شوند؛ اگر یادداشتی در هر دو باشد، نسخه‌ای که زمان ویرایش جدیدتری دارد برنده است.
  • دسته‌بندی‌ها و برچسب‌های سفارشی: اجتماع دو مجموعه، بدون تکرار.
  • تنظیمات: مقادیر فایل ورودی روی تنظیمات فعلی اعمال می‌شوند؛ اگر فضای کاری فعال وجود نداشته باشد به فضای پیش‌فرض برمی‌گردد.
  • آخرین ذخیره سریع: تازه‌ترین مورد نگه داشته می‌شود.
  • در پایان، یک مرحله مهاجرت خودکار اجرا می‌شود تا ساختار داده‌ها با نسخه فعلی هم‌خوان شود.
قبل از ورود اطلاعات

همیشه اول یک خروجی JSON از وضعیت فعلی بگیرید. اگر فایل اشتباهی وارد کنید، یادداشت‌ها پاک نمی‌شوند ولی ممکن است با داده فایل ورودی ترکیب شوند.

مهاجرت خودکار

هر بار که اکستنشن نصب یا به‌روز می‌شود و هر بار که مرورگر باز می‌شود، داده‌ها بررسی و در صورت نیاز ترمیم می‌شوند: یادداشت بدون فضای کاری معتبر به فضای پیش‌فرض منتقل می‌شود، تم قدیمی default به blue تبدیل می‌شود، فیلدهای جاافتاده با مقدار پیش‌فرض پر می‌شوند و برچسب‌ها یکدست‌سازی می‌شوند.

انتقال به کامپیوتر دیگر

  1. در کامپیوتر اول: تنظیمات ← Export JSON و فایل را ذخیره کنید.
  2. کلیپ‌نوت را طبق راهنمای نصب روی کامپیوتر دوم نصب کنید.
  3. در تنظیمات ← Import JSON همان فایل را انتخاب کنید.
  4. بعد از اطمینان از درست بودن یادداشت‌ها، فایل بکاپ را از مسیرهای عمومی پاک کنید.

پاک کردن کامل داده‌ها

دکمه Clear All Data در بخش داده، همه یادداشت‌ها، دسته‌بندی‌ها، فضای کاری، برچسب‌ها و تنظیمات را حذف می‌کند. قبل از اجرا یک پیام تأیید نمایش داده می‌شود و این عمل قابل بازگشت نیست.

پیشنهاد بکاپ‌گیری

قبل از به‌روزرسانی اکستنشن یا تغییر پروفایل کروم، یک خروجی JSON بگیرید. چون هیچ سروری در کار نیست، تنها نسخه پشتیبان شما همان فایل است.

Data, backup & moving

Where your data lives, what the backup file looks like, what merges with what on import, and how to move to another computer without losing a note.

Where the data is stored

Everything lives in chrome.storage.local under these keys:

KeyContent
clipnote_notesAll notes
clipnote_settingsAppearance, editor and language settings
clipnote_workspacesWorkspaces
clipnote_categoriesCategories
clipnote_custom_tagsCustom tags
clipnote_last_quick_saveInfo about the last quick save, used by the popup banner
clipnote_update_infoResult of the last update check (6-hour cache)
clipnote_last_notified_versionThe version that already produced a notification

Anatomy of a note

Each note carries these fields: id, title, content, tags, category, color, isFavorite, isPinned, createdAt, updatedAt, workspaceId, a source object (capture type, page title, page URL and capture time) and a lock object for protection.

Exporting (backup)

Under Settings → Data there are three buttons:

  • Export JSON: the full backup, named like clipnote-backup-2026-08-25.json. It contains notes, settings, categories, workspaces, custom tags and counts, and its format is version 3.
  • Export TXT: a readable text file for archiving or reading in a text editor; for each note it writes the title, workspace, category, tags, created and updated dates, source URL and the full content.
  • Import JSON: restoring a backup file with smart merging (explained below).

What happens on import

Importing does not erase your current data; it merges:

  • Workspaces: merged by id; the name comes from the imported file and the earliest creation time is kept. The default workspace is always guaranteed.
  • Notes: merged by id; when a note exists in both, the copy with the newer update time wins.
  • Categories and custom tags: the union of both sets, without duplicates.
  • Settings: values from the imported file are applied over the current ones; if the active workspace no longer exists it falls back to the default workspace.
  • Last quick save: the most recent entry is kept.
  • Finally an automatic migration step runs so the data structure matches the current version.
Before importing

Always export your current state to JSON first. Importing the wrong file will not delete your notes, but it can mix them with the imported data.

Automatic migration

Every install, update and browser start triggers a data check and repair when needed: a note without a valid workspace is moved to the default one, the legacy default theme becomes blue, missing fields are filled with defaults, and tags are normalised.

Moving to another computer

  1. On the first computer: Settings → Export JSON and keep the file.
  2. Install ClipNote on the second computer following the install guide.
  3. Choose that file under Settings → Import JSON.
  4. Once you have confirmed the notes are there, delete the backup file from public locations.

Wiping all data

The Clear All Data button in the Data section removes every note, category, workspace, tag and setting. A confirmation is shown first and the action cannot be undone.

Backup advice

Export to JSON before updating the extension or changing your Chrome profile. Because there is no server, that file is your only copy.
